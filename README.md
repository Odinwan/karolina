# «Волшебный декабрь» — missmalofii

Одностраничный сайт: посетитель сканирует QR-код, открывает конверт со случайным посланием, может сохранить его карточкой, забрать PDF-гайд и записаться на сессию.

Стек: React + TypeScript + Vite + Tailwind CSS. Шрифты подключены локально, без Google Fonts. Внешних запросов нет.

## Запуск

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # сборка готового сайта в папку dist/
npm run preview    # посмотреть собранный сайт
```

## Что и где менять

| Что | Где |
|---|---|
| Ссылка на запись, контакты, имя, бренд, подпись на карточке | `src/config/site.ts` |
| PDF-гайд | заменить файл `public/guide/missmalofii-december-guide.pdf` (имя оставить тем же) **или** указать внешнюю ссылку в `guideUrl` в `src/config/site.ts` |
| Тексты посланий | `src/config/messages.ts` |

### Ссылка на запись
В `src/config/site.ts` заполни `bookingUrl`, например `'https://t.me/username'`.
Пока поле пустое, кнопка «записаться на сессию» не показывается, чтобы на сайте не было нерабочих кнопок.

### Instagram, Telegram и другие ссылки
Ссылки задаются в `contactLinks` в `src/config/site.ts` и выводятся кнопками в финальном блоке.
Формат: `{ label: 'instagram', url: 'https://…', icon: 'instagram' }`. Значения `icon`: `instagram`, `telegram`, `link`.
Если список пустой, блок не выводится.

### Послания
В `src/config/messages.ts` скопируй любую строку `{ id: 'm101', text: '...' }` и поменяй текст.
`id` должен быть уникальным. Абзацы разделяются пустой строкой.
Можно добавить `theme: 'послание о любви к себе'`, тогда над текстом будет своя подпись. Без неё выводится «декабрьское послание» (`DEFAULT_THEME`).
Короткие фразы автоматически показываются крупнее, длинные мельче.
Посетитель получает послания по кругу в случайном порядке, без повторов.

### Гайд и обложка
- Сам файл: `public/guide/missmalofii-december-guide.pdf`.
- Картинка обложки на сайте: `src/assets/guide-cover.jpg`. Если поменяешь гайд, замени и её — это первая страница PDF шириной около 700 px.

### Музыка
Трек лежит в `public/audio/most-wonderful-time.mp3`, путь и громкость задаются в `musicUrl` / `musicVolume` в `src/config/site.ts`.
Браузеры не разрешают звук до первого действия посетителя, поэтому музыка включается после первого касания (например, по кнопке «открыть моё послание»). Кнопка «музыка» в правом нижнем углу выключает её, и выбор запоминается.
Чтобы убрать музыку совсем, поставь `musicUrl: ''`.

### Звуки
Короткие звуки (шорох письма при открытии конверта, искры салюта, шелест при «ещё одно послание») лежат в `public/sfx/`.
Их лицензии записаны в `public/sfx/CREDITS.md` (все CC0). Громкость каждого звука задаётся в `src/lib/sfx.ts`.
Кнопка «музыка» выключает и музыку, и звуки.

## Публикация и QR-код

После любой правки нужно выполнить `npm run build`. Получится папка `dist/`, это и есть весь сайт.
Пути в сборке относительные, поэтому сайт работает на любом хостинге и в любой папке.

Самые простые варианты:
1. **Netlify Drop** — https://app.netlify.com/drop: перетащи папку `dist`, получишь адрес вида `https://имя.netlify.app` (имя меняется в настройках сайта).
2. **Vercel / GitHub Pages / Cloudflare Pages**: подключи репозиторий, команда сборки `npm run build`, папка `dist`.
3. **Обычный хостинг** (Timeweb, Beget, REG.RU): загрузи *содержимое* папки `dist` в корень сайта по FTP или через файловый менеджер.

QR-код: возьми итоговый адрес (лучше на своём домене) и сгенерируй код в любом генераторе статичных QR. Динамические «бесплатные» сервисы часто со временем отключают ссылку.
Перед печатью проверь код на нескольких телефонах.
